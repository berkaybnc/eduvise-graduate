Platforma Genel Bakış

EduVise, öğrencilerin yeteneklerini analiz eden, onlara özel öğrenme yolları (roadmap) sunan ve eğitim sürecini oyunlaştırma ile destekleyen modern bir akıllı eğitim platformudur.


  • Kişiselleştirilmiş Öğrenme (Adaptive Learning)
  • Geniş Çaplı Dil Modeli (LLM) Entegrasyonu
  • Tam yığın (Full-stack) modern mimari

Frontend Mimarisi

  • React.js & Vite: Hızlı derleme süreleri ve modern bileşen tabanlı yapı.
  • Tailwind CSS: Duyarlı (responsive) ve ölçeklenebilir tasarım sistemi.
  • Zustand: Merkezi ve asenkron state (durum) yönetimi.

Backend Mimarisi

  • Python & FastAPI: Yüksek performanslı asenkron RESTful API tasarımı.
  • SQLAlchemy & SQLite: Güçlü ORM yapısı ve ilişkisel veri modeli yönetimi.
  • Modüler Yapı: Auth, Kurs, Değerlendirme, Forum ve Ödeme modülleri.

Kod İncelemesi: Auth Modülü

Güvenli ve Asenkron Kimlik Doğrulama


const handleSubmit = async (e) => {
  e.preventDefault();
  const response = await api.post('/auth/login', {
    email: formData.email,
    password: formData.password,
  });
  
  const token = response.data.access_token;
  const meResponse = await api.get('/auth/me', {
    headers: { Authorization: `Bearer ${token}` }
  });
  
  setAuth(meResponse.data, token);

  if (meResponse.data.role === 'instructor') {
    navigate('/instructor/dashboard');
  } else {
    navigate('/dashboard');
  }
};

Kod İncelemesi: Optimizasyon

Cascading Render hatalarını önleyen yaklaşım


// React Hook içerisinde eşzamanlı render'ı önlemek
useEffect(() => {
  if (location.state?.openCreateTab) {
    const timer = setTimeout(() => {
      resetCreation();
      setActiveTab('create');
      
      // Route state'ini temizle
      navigate(location.pathname, { replace: true, state: {} });
    }, 0);
    return () => clearTimeout(timer);
  }
}, [location.state, location.pathname, navigate]);
